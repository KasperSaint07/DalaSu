# 06. Требования к системе SuAqyl (DAL-16)

Приоритеты по MoSCoW: **M** (Must), **S** (Should), **C** (Could), **W** (Won't в этой версии).
Каждое требование проверяемо: есть число или критерий приёмки.

## Функциональные требования (FR)

| ID | Требование | Критерий приёмки | Приоритет |
|---|---|---|---|
| FR-01 | Расчёт ET₀ по FAO-56 Penman-Monteith из метеоданных | Расхождение с ET₀ от Open-Meteo ≤ 0.3 мм/сут на тестовом наборе; юнит-тесты на FAO-56 Example 18 проходят | M |
| FR-02 | Baseline-оценка ET₀ на данных US-Ne2 | Посчитаны RMSE и R² против eddy covariance | M |
| FR-03 | Модели Random Forest и XGBoost для ET₀ | Обе модели обучены, метрики RMSE/R² записаны в `reports/` | M |
| FR-04 | Сравнение FAO-56 baseline и гибридных моделей | Таблица RMSE/R² для 3 подходов; результат воспроизводится одной командой | M |
| FR-05 | Расчёт ETc = ET₀ × Kc по таблицам FAO-56 | Для каждой поддерживаемой культуры заданы Kc по 4 стадиям | S |
| FR-06 | Водный баланс корневой зоны (Dr) и порог полива | Dr считается по формуле FAO-56; тест на эталонном примере | S |
| FR-07 | Рекомендация «когда и сколько поливать» | Для поля выдаются дата и объём (мм) на ближайшие 7 дней | S |
| FR-08 | Резервный режим без свежего снимка Sentinel-2 | При отсутствии снимка > 5 дней рекомендация строится по чистому FAO-56 без ошибки | S |
| FR-09 | Регистрация поля, культуры и даты посадки | Поле сохраняется и восстанавливается после перезапуска | S |
| FR-10 | Дневник поливов | Запись полива учитывается в следующем расчёте Dr | C |
| FR-11 | Push-уведомления с рекомендацией | Уведомление приходит в день рекомендованного полива | C |
| FR-12 | График сезона с NDVI | График отображает дефицит влаги и NDVI за сезон | C |
| FR-13 | Казахский и русский интерфейс | Все экраны переведены на оба языка | C |
| FR-14 | SHAP-анализ важности признаков | Построен график вклада признаков для лучшей модели | C |
| FR-15 | Physics-informed нейросеть, Sentinel-1 | — | W |

## Нефункциональные требования (NFR)

| ID | Требование | Критерий приёмки | Приоритет |
|---|---|---|---|
| NFR-01 | Воспроизводимость | Фиксированный seed; чистая установка и запуск по README дают те же метрики | M |
| NFR-02 | Точность гибридной модели | RMSE гибрида ниже RMSE FAO-56 baseline на тестовой выборке US-Ne2 | M |
| NFR-03 | Корректность данных | Выбросы и пропуски US-Ne2 обработаны; доля пропусков после очистки задокументирована | M |
| NFR-04 | Качество кода | Тесты проходят через `pytest`; запуск без ручной настройки (pyproject.toml) | M |
| NFR-05 | Время ответа рекомендации | Ответ API ≤ 3 с при запросе по одному полю | S |
| NFR-06 | Стоимость данных | Используются только бесплатные источники (Open-Meteo, Sentinel-2, SoilGrids) | S |
| NFR-07 | Объяснимость | Для рекомендации показан вклад дефицита влаги и осадков | C |
| NFR-08 | Количественная валидация на данных Казахстана | — (станции eddy covariance в Казахстане нет; валидация качественная) | W |
